# AGENTS.md

Notes for coding agents working in this repo. Read this before changing anything.

## Layout

```
apps/web/          TanStack Start app, deployed by Cloudflare Workers Builds (wrangler.jsonc)
  src/routes/      File-based routes. src/routeTree.gen.ts is generated, never edit it.
packages/backend/  Convex functions and schema, all in convex/
  convex/_generated/       Generated by `convex dev`. Committed, never edit it.
packages/ui/       shadcn/ui components on Base UI, plus the shared globals.css
scripts/           setup.ts, sync-env.ts, cloudflare-build.ts
```

Workspace packages use the `@tanstack-convex-starter/` scope. The web app imports the Convex API as
`@tanstack-convex-starter/backend/convex/_generated/api` and components as `@tanstack-convex-starter/ui/components/<name>`.
Inside apps/web, `#/` maps to `src/`.

## Commands

Run everything from the repo root with Bun.

| Command         | What it does                                                        |
| --------------- | ------------------------------------------------------------------- |
| `bun install`   | Install dependencies and the Vite+ git hooks                        |
| `bun run setup` | One-time local setup: local Convex deployment and env               |
| `bun run dev`   | Convex dev and the web dev server on http://localhost:3000          |
| `bun run check` | Format, lint and type check (`vp check`). Fix with `vp check --fix` |
| `bun run test`  | Unit tests (Vitest via `vp test`, convex-test for Convex)           |
| `bun run build` | Production build of apps/web                                        |

The pre-commit hook runs `vp check --fix` on staged files. Don't skip it with `--no-verify`.

## Rules

- Tooling is Vite+. Import test helpers from `vite-plus/test` and config helpers from
  `vite-plus`, not `vitest` or `vite`. The `vite-plus/prefer-vite-plus-imports` lint rule
  enforces this.
- Add shadcn components from apps/web so they land in packages/ui:
  `cd apps/web && bunx --bun shadcn@latest add <name>`. Components use Base UI, not Radix.
  A Base UI `Button` keeps `role="button"` even when it renders a link, so for navigation
  use `<Link className={buttonVariants()}>`.
- There is no auth. Every Convex function is public, so anyone with the deployment URL can
  call it. Don't store private data until sign-in is added back.
- Env vars a Convex function needs must be set with `bunx convex env set` in
  packages/backend.
